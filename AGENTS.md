# Repository guidance

- Preserve the restrained luxury visual language: black, graphite, fog, and silver.
- Keep public claims within the approved language boundaries and maintain the distinction between the global non-ballistic shell and separate jurisdiction-controlled configurations.
- Keep Project Sable public content centralized in `src/content/site.ts`.
- Do not introduce stock imagery, weapons, tactical aesthetics, costume styling, or neon effects.
- Use strict TypeScript and prefer server-rendered or generated markup with minimal client JavaScript.
- Maintain keyboard access, WCAG-conscious contrast, and reduced-motion behavior.
- Run formatting, lint, type-checking, tests, and the production build before completing work.
- Never expose server credentials to browser code.
- Do not add tracking, cookies, or major dependencies without explicit approval.
- Do not add ecommerce or protective-product checkout.
- Preserve the access-request provider abstraction.
- Avoid large dependencies for small visual effects.
